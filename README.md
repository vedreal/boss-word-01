Exactly one word describing the boss — no phrase, no caption, no explanation. Ten candidate words are scored against the judge's brief (single word about a boss, funny on its own, rings true, fresh, travels across industries) and the winner is written to `/output/entry.txt`. The winning word: **Seagull** — the seagull manager who swoops in, squawks, craps all over the work, and flies off.

## Run it

```sh
python3 main.py
```
